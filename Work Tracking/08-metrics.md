# Metrics

## Product Metrics

- Trainer activation: trainer invites first client.
- Client activation: client completes onboarding.
- Coaching loop activation: trainer assigns workout and client completes it.
- Weekly active trainers.
- Weekly active clients.
- Workout completion rate.
- Check-in completion rate.
- Nutrition logging rate.
- Trainer response time.
- AI recommendation approval rate.

## Client Health Metrics

- Adherence trend.
- Training consistency.
- Nutrition consistency.
- Recovery trend.
- Readiness score.
- Missed workout streak.
- PR frequency.
- Plateau duration.

## Business Metrics

- Trainers onboarded.
- Clients per trainer.
- Trainer retention.
- Client retention.
- Paid conversion once payments launch.
- Monthly recurring revenue once payments launch.

## Engineering Metrics

- Build success rate.
- Test pass rate.
- Crash-free sessions.
- API error rate.
- Notification delivery rate.
- AI recommendation latency.

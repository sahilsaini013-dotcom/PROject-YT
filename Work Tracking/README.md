# Training Hub Work Tracking: Operating Board

This folder tracks the work for Training Hub. Use it as the operating board for planning, building, reviewing, and shipping.

Use this folder for action, status, ownership, risk, and releases. Product memory belongs in `../Brain`.

## Start Here

- `00-project-dashboard.md` - current project snapshot.
- `01-roadmap.md` - milestone plan by phase.
- `02-backlog.md` - prioritized work queue.
- `03-sprint-board.md` - active sprint board.
- `04-decision-log.md` - product and technical decisions.
- `05-risk-log.md` - risks, blockers, and mitigation plans.
- `06-weekly-status.md` - running weekly updates.
- `07-release-log.md` - shipped versions and release notes.
- `08-metrics.md` - product, engineering, and business metrics.
- `09-research-log.md` - user research, market notes, and evidence.
- `10-glossary.md` - shared project language.
- `templates/` - reusable templates for tasks, decisions, status updates, and releases.

## Workflow

1. Add new ideas to `02-backlog.md`.
2. Move selected work into `03-sprint-board.md`.
3. Record major choices in `04-decision-log.md`.
4. Track uncertainty in `05-risk-log.md`.
5. Summarize progress in `06-weekly-status.md`.
6. Log shipped work in `07-release-log.md`.

## Use Work Tracking For

- Backlog
- Sprint board
- Weekly status
- Risks and blockers
- Decisions
- Releases
- Metrics

## Do Not Use Work Tracking For

- Long-term product vision
- AI philosophy
- Core user-flow explanations
- Data model brainstorming

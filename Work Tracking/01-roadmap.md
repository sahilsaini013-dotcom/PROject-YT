# Roadmap

## Milestone 1: Product Requirements and Build Blueprint

Goal: turn the idea into a decision-ready build plan.

Deliverables:

- MVP scope
- Screen inventory
- User journeys
- Data model draft
- API/service map
- Backlog with priorities
- Sprint 1 plan

Exit criteria:

- An engineer or design agent can begin implementation without guessing the core product shape.

## Milestone 2: UX Prototype

Goal: create a usable prototype for the core trainer and client experience.

Deliverables:

- Trainer dashboard wireframes
- Client mobile app wireframes
- Today screen
- Workout player
- Nutrition logging
- Client profile
- AI review inbox
- Program builder

Exit criteria:

- The core workflow can be clicked through from trainer invite to client workout completion and trainer review.

## Milestone 3: App Foundation

Goal: stand up the real product foundation.

Deliverables:

- Auth
- User roles
- Trainer-client invites
- Client profiles
- Basic backend
- Database schema
- Mobile app shell
- Web dashboard shell

Exit criteria:

- Trainers and clients can sign in and see role-specific starting screens.

## Milestone 4: Coaching Core

Goal: ship the core coaching loop.

Deliverables:

- Program builder
- Workout assignment
- Workout logging
- Recovery check-ins
- Nutrition targets
- Simple meal logging
- Messaging
- Notifications
- Progress dashboard

Exit criteria:

- A trainer can assign a plan and review client completion, nutrition, and recovery data.

## Milestone 5: AI Coaching Assistant

Goal: help trainers prioritize client action.

Deliverables:

- AI recommendation inbox
- Client readiness summaries
- Push/pull-back suggestions
- Nutrition-performance insights
- Weekly client summaries
- Trainer approval flow

Exit criteria:

- AI recommendations are explainable, trainer-controlled, and based on client data.

## Milestone 6: Business Layer

Goal: add trainer monetization tools.

Deliverables:

- Packages
- Payment links
- Subscriptions
- Invoices
- Billing status
- Revenue dashboard

Exit criteria:

- Trainers can manage paid client relationships from Training Hub.

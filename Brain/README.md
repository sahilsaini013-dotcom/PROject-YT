# Training Hub Brain: Project Memory

This folder is the project memory for Training Hub. It captures what the product is, how it should think, how users move through it, and what the core product decisions mean.

Use this folder for durable product truth, not task tracking.

## Files

- `01-product-north-star.md` - what Training Hub is and why it exists.
- `02-core-user-flows.md` - trainer and client workflows.
- `03-feature-map.md` - major product areas and what belongs in each.
- `04-ai-coaching-brain.md` - how the AI assistant should think and act.
- `05-data-model-notes.md` - core objects the app needs to store.
- `06-roadmap.md` - phased product build direction.
- `07-open-questions.md` - decisions to revisit later.

## Use Brain For

- Product vision
- User flows
- Feature logic
- AI coaching behavior
- Data model thinking
- Open product questions

## Do Not Use Brain For

- Sprint tasks
- Weekly status
- Release notes
- Risk tracking
- Backlog management

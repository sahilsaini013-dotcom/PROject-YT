# Core User Flows

## Trainer Onboarding

1. Trainer creates account.
2. Trainer sets business profile, coaching style, specialties, and default availability.
3. Trainer creates first client invite.
4. Trainer builds or imports a starter program.
5. Trainer sets default check-in and nutrition preferences.

## Client Onboarding

1. Client accepts trainer invite.
2. Client completes profile: goal, height, weight, injuries, experience level, schedule, equipment.
3. Client completes baseline check-in: sleep, soreness, energy, stress, nutrition habits, motivation.
4. Client connects wearable data if available.
5. Client lands on the Today screen.

## Trainer Assigns Program

1. Trainer opens client profile.
2. Trainer selects or creates program.
3. Trainer sets schedule, start date, progression rules, and notes.
4. Trainer assigns nutrition targets and check-in cadence.
5. Client receives notification.

## Client Completes Workout

1. Client opens Today screen.
2. Client starts assigned workout.
3. Client logs sets, reps, weight, RPE, pain notes, and substitutions.
4. Client completes session summary.
5. AI updates readiness and flags anything important for trainer review.

## Client Nutrition Check-In

1. Client logs meals, water, supplements, and notes.
2. Client can attach meal photos.
3. App compares intake behavior to trainer targets.
4. Trainer sees nutrition adherence and patterns.
5. AI connects nutrition to performance and recovery.

## Trainer Reviews Client

1. Trainer opens AI review inbox.
2. Trainer sees clients sorted by attention needed.
3. Trainer reviews recommendation and source data.
4. Trainer approves, edits, or dismisses suggested action.
5. Client receives trainer-approved message or program adjustment.
